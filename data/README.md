# Data

This directory contains the datasets used for the E-Commerce Sales Data Analysis project.

## Dataset Information

The project dataset contains 1,200 e-commerce order records and 14 attributes covering orders, customers, products, pricing, payments, marketing sources, and order status.

## Data Privacy

The original internship dataset may contain potentially sensitive or organization-specific information. Raw internship data should not be publicly shared without explicit authorization.

If the dataset is published, it should be anonymized and cleared for public use.

## Dataset Fields

Key fields include:

- Order ID
- Customer ID
- Order Date
- Product
- Quantity
- Unit Price
- Total Price
- Payment Method
- Order Status
- Referral Source
- Coupon Code
- Tracking Number
